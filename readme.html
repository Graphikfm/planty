# Projet WordPress – Site vitrine avec partie administration ## Présentation du projet Ce projet a été réalisé dans le cadre d’une **formation en développement web** afin de mettre en pratique plusieurs notions essentielles du développement front-end et back-end avec WordPress. L’objectif principal était de concevoir un site WordPress personnalisé intégrant : - une interface publique responsive - une partie administration WordPress - une gestion de contenu dynamique - une architecture de fichiers propre - une base de données MySQL - des intégrations HTML / CSS / PHP / JavaScript Le projet met particulièrement l’accent sur : l’intégration responsive la structuration d’un projet WordPress la personnalisation graphique la gestion d’une base de données locale la manipulation d’un environnement de développement local --- # Objectifs pédagogiques du projet Ce projet de formation permet de comprendre : - le fonctionnement de WordPress - l’organisation des fichiers WordPress - la connexion entre PHP et MySQL - la création d’interfaces responsives - la gestion d’un environnement local - la personnalisation d’un thème - les bonnes pratiques d’intégration web --- # Responsive Design & Intégration Le site a été conçu en respectant les principes du **Responsive Design** afin d’assurer une expérience fluide sur : - Ordinateur - Tablette - Mobile ## Particularités graphiques Le projet utilise des éléments décoratifs positionnés dynamiquement grâce aux propriétés CSS : ```css position: relative; position: absolute; ``` Cette technique permet : - d’ajouter des formes décoratives - de superposer des éléments graphiques - de créer une interface moderne - de conserver une mise en page adaptable selon la taille d’écran ### Exemple utilisé dans le projet ```css .container { position: relative; } .decoration-shape { position: absolute; top: 0; right: 0; } ``` --- # Technologies utilisées ## Front-end - HTML5 - CSS3 - JavaScript ## Back-end - PHP - WordPress ## Base de données - MySQL ## Outils de développement - Local - GitHub - phpMyAdmin --- # Installation du projet en local ## 1️Télécharger le projet Clonez le dépôt GitHub : ```bash git clone URL_DU_DEPOT ``` ou : - cliquez sur `Code` - puis `Download ZIP` Extrayez ensuite le projet dans votre dossier local. --- # Installation avec Local Le projet est prévu pour fonctionner avec : ## Local Téléchargement : https://localwp.com/ --- # Création du site dans Local ## 1. Ouvrir Local Lancez l’application Local. --- ## 2. Créer un nouveau site Cliquez sur : ```text + Create a new site ``` --- ## 3. Nommer le projet Choisissez le nom souhaité pour votre site local. Exemple : ```text mon-projet-wordpress ``` --- ## 4. Choisir l’environnement Sélectionnez : ```text Preferred ``` --- ## 5. Configuration WordPress Les identifiants créés ici pourront être modifiés ensuite directement dans l’interface de Local. Ouvrir Adminer ou phpMyAdmin Depuis Local : ```text Database → Open Adminer ``` --- ## 2. Importer le fichier SQL Le projet contient un fichier : ```text local.sql ``` Importez-le dans la base de données du projet. --- # Importation des fichiers WordPress Remplacez ensuite les fichiers du site Local par ceux du dépôt GitHub : - wp-content - thème personnalisé - plugins éventuels - fichiers du projet --- # Vérification du fichier wp-config.php Le fichier : ```text wp-config.php ``` doit contenir les informations de connexion à la base de données fournies automatiquement par Local. Ces informations peuvent varier selon votre configuration Local. Vous pouvez les retrouver dans : ```text Local → Site → Database ``` --- # Accès à l’administration WordPress Une fois l’installation terminée : ## URL admin ```text http://nom-du-site.local/wp-admin ``` --- ## Identifiants par défaut | Champ | Valeur | |---|---| | Nom d’utilisateur | Fabien.mari | | Mot de passe | root | Ces identifiants peuvent être modifiés directement dans WordPress ou dans Local. --- # Lancer le projet Depuis Local : - démarrez le site - cliquez sur : ```text Open Site ``` ou : ```text WP Admin ``` --- # Structure principale du projet ```text wp-admin/ wp-content/ wp-includes/ wp-config.php local.sql ``` --- # Apprentissages réalisés Grâce à ce projet, plusieurs compétences ont été développées : création d’un projet WordPress complet gestion d’une base de données MySQL utilisation d’un environnement local intégration responsive manipulation du CSS avancé personnalisation d’interfaces organisation des fichiers d’un projet web utilisation de GitHub pour le versionning --- # Auteur Projet réalisé par : ```text Fabien Mari ``` dans le cadre d’une formation en développement web. ---
